# 更强的潜影盒 (Stronger Shulker Box)

一个 Minecraft 1.21.1 NeoForge 模组，让潜影盒可以互相嵌套存放，最多嵌套 5 层。

## 功能特性

### v1.1.0 新增：背包内直接打开潜影盒
- 在背包界面内，鼠标悬停在潜影盒物品上 **右键点击**，即可直接打开该潜影盒的原生 GUI
- 支持 **嵌套逐层打开**：在已打开的潜影盒界面内，右键其中的潜影盒即可继续深入
- 一次只展示一层，**ESC 逐层退出**（先退回上一层潜影盒，最后退回背包）
- 完全沿用原版潜影盒界面，不重写 GUI

### 核心机制
- 潜影盒内可放置潜影盒，最多嵌套 **5 层**（一个潜影盒本身算第 1 层）
- 深度校验闭合：任意潜影盒物品的相对嵌套深度恒 ≤ 5，无法通过拆装绕过
- 所有修改实时写回物品数据，关闭界面后内容完整保留

## 环境要求

| 项目 | 版本 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.176+（FCL 21.1.248 实测兼容） |
| Java | 21 |

## 构建

```bash
gradle build --no-daemon
```

构建产物位于 `build/libs/strongershulkerbox-<version>.jar`。

## 安装

将 jar 放入 Mods 目录（FCL：`FCL/.minecraft/versions/<版本>/mods/`），完全退出游戏后重启。

## 使用

1. 打开背包（默认 E 键）
2. 鼠标悬停在任意潜影盒上，**右键**
3. 进入该潜影盒界面；若其中有潜影盒，再次右键可继续深入
4. 按 **ESC** 逐层退出
